# Papan pemuka dan sejarah

- Ringkasan hanya menunjukkan ganjaran menunggu kelulusan dan pendahulu hari ini.
- Seksyen kad Anak-anak disembunyikan pada papan pemuka; pengurusan anak dan peranti masih tersedia melalui menu Anak-anak.
- Kemajuan Keluarga menunjukkan anak, bilangan tugasan dan mata. Lajur peratus penyelesaian serta hari berturut-turut tidak dipaparkan.
- Log aktiviti memaparkan 20 rekod terkini keluarga daripada lejar mata (termasuk pembatalan) dan permintaan ganjaran, tanpa mengubah sejarah asal.
- Tarikh paparan menggunakan `dd/mm/yyyy` dan waktu seperti `8 pagi` atau `8:30 malam`, dalam zon waktu aplikasi `Asia/Kuala_Lumpur`. Nilai input kalendar asli dan simpanan kekal ISO untuk keserasian pelayar.
- Tindakan tugasan kini sentiasa nyahaktif, bukan padam fizikal. Tugasan tidak aktif kekal dalam senarai ibu bapa, boleh disunting dan diaktifkan semula; tidak ditawarkan untuk diselesaikan oleh anak.
- Rekod tugasan yang telah dipadam secara fizikal sebelum perubahan ini tidak boleh dipulihkan tanpa sandaran.
- Peranti tidak aktif mempunyai borang padam dengan pengesahan. Pelayan menolak pemadaman peranti aktif dan peranti keluarga lain; pemadaman direkodkan dalam audit tanpa token. Tiada peranti sebenar dipadam semasa ujian.
